**ROOTBOOT BIOS** - абсолютно ничем не примечательный 32-битный экспериментальный биос, написанный от балды мной))))

## требования (ВАЖНОЁЁ!!!!!!!!!):
- NASM ≥ 2.15
- MinGW (GCC) ≥ 10, обязательно с -m32
- `ld` `objcopy` из состава MinGW / binutils
- QEMU для запуска (qemu-system-i386)
